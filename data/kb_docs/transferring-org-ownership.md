---
title: "Transferring Organization Ownership"
category: admin
---
Every org has exactly one "Owner" (the original subscriber), distinct from regular admins — the Owner is the only role that can delete the org entirely or change the billing payment method's account holder.

To transfer ownership: Admin Console → Members → select the target admin → "Transfer Ownership." The current Owner must confirm via a re-authentication prompt. The previous Owner is automatically demoted to a regular admin, not removed from the org.

Ownership cannot be transferred to a non-admin — promote the target member to admin first if needed.
