---
title: "Admin Console Overview"
category: admin
---
The Admin Console (Team/Enterprise only, admin role required) has four sections:

- **Members** — invite, remove, and view seat status for org members.
- **Billing** — invoices, payment method, plan changes, seat count and cost breakdown.
- **Security** — SSO/SAML configuration, session timeout policy, IP allowlisting (Enterprise only).
- **Usage** — org-wide pooled message usage, per-member breakdown, and historical trends.

The first member to subscribe an organization to Team/Enterprise becomes the default admin (Owner role) and can promote other members to admin from Members → select member → "Grant Admin Role."
