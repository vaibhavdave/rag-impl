---
title: "API Usage vs. Subscription Usage"
category: usage
---
Your consumer subscription (Free/Pro/Team/Enterprise access to the chat app) and API usage (building your own application against Nimbus models) are billed and rate-limited completely separately, even under the same account email.

A Pro subscription does not include any API credit — API usage is pay-per-token and requires a separate API key and payment method set up under Developer Console → API Keys. Likewise, heavy API usage does not count against or affect your subscription's daily message limit in the chat app.

If you're seeing rate-limit or billing behavior you don't expect, first confirm whether the activity in question happened through the chat app (subscription) or through an API key (API billing) — the two systems have independent limits, dashboards, and support paths.
