title: "Nimbus AI Plan Overview"
category: plans
---
Nimbus AI offers four subscription tiers:

- **Free** — 20 messages/day, standard model, no file uploads, 7-day chat history.
- **Pro** ($20/month) — 500 messages/day, priority access during peak hours, file uploads up to 20MB, unlimited chat history, larger context window (200K tokens).
- **Team** ($25/user/month, 3+ seats) — everything in Pro, plus a shared workspace, pooled usage across the org, an admin console, and centralized billing.
- **Enterprise** (custom pricing) — everything in Team, plus SSO/SAML, custom data retention policies, a dedicated support contact, and volume-based rate limits negotiated per contract.

There is also a separate **API plan**, billed per token rather than per seat, intended for developers building on top of Nimbus models. API usage and consumer subscription usage are tracked and billed independently — a Pro subscription does not include API credits.

Plan changes take effect based on the type of change: upgrades apply immediately, downgrades apply at the start of the next billing cycle (see "Upgrading and Downgrading Your Plan").
